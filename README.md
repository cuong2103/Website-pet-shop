# 🛒 Website CRUD & Simple Payment System

Website quản lý sản phẩm với chức năng CRUD và thanh toán đơn giản  
(Dùng cho mục đích học tập – không liên kết ngân hàng hay QR)

---

## 📌 Giới thiệu

Đây là dự án web backend được xây dựng nhằm luyện tập:

- Thao tác CRUD (Create, Read, Update, Delete)
- Quản lý dữ liệu bằng MySQL
- Mô phỏng quy trình thanh toán đơn giản
- Áp dụng mô hình MVC

Phù hợp cho sinh viên học PHP/Laravel.

---

## ✨ Chức năng chính

✔ Thêm / sửa / xóa / xem sản phẩm  
✔ Quản lý người dùng  
✔ Giỏ hàng đơn giản  
✔ Thanh toán thủ công (xác nhận đơn hàng)  
✔ Lưu lịch sử đơn hàng
